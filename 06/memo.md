6章ではアセンブラについて学習する。  

- 基本版アセンブラ
  - シンボル参照を含まないプログラムを変換する。
  - Parser
    - 一行ごとに, フィールドに分けていく。
    - 初期化で空白, コメントを消す。コマンドをリストで格納。
    - A命令のときは@以降を, C命令のときはdest,cmp,jumpを抜き出す。
  - Code
    - ニーモニックを受け取り, バイナリを返す関数を作成。  
- 完全版アセンブラ
  - シンボル参照を備えている, 拡張されたアセンブラ。
  - SymbolTable(追加)
    - シンボルとそれに対応するアドレスを管理する。
  - Paser(改良)
    - ()がくると, L命令として, シンボルを渡す。
  - Main
    - 2回読み込む。1回目は,シンボルテーブルを作成する.L命令に当たったとき, そのときの番号とシンボルを対応させておく。
    - 2回目は, 基本版と同じ。フィールドをひとつづつ見ていき, バイナリに変換して書き込む。
